## 宏

宏包括：声明式宏(macro_rules!) 和 过程宏。

macro_rules!宏是在语法层面工作。

```rust
use std::io::stdin;
macro_rules! scanline {  // 声明式宏,必须在函数之内才能进行调用
    ($x:expr) => ({
        stdin().read_line(&mut $x).unwrap();
        let _ = $x.trim();
    });
    () => ({
        let mut s = String::new();
        stdin().read_line(&mut s).unwrap();
        s
    })
}

fn main() {
    let mut input = String::new();
    scanline!(input);
    println!("I read : {}", input);
    let a = scanline!();
    println!("Hi {} ", a );
}
```
